# ---------------------------------------------------------------------------
# HOW IT WORKS
# ---------------------------------------------------------------------------
# When you pick "Let's chat!", Starby says one OPENING line and shows 5 TOPICS,
# picked at random from every TOPIC in this file (plus a Back button). So every
# chat can start differently. The more TOPICS, the more variety.
#
# Each TOPIC is a little tree: Starby says something, you pick an answer, he
# replies, you pick again... as deep as you like.
#
# ---------------------------------------------------------------------------
# THE PIECES (cheat sheet)
# ---------------------------------------------------------------------------
#   OPENING: line              What he says when the chat opens (one picked at random).
#   TOPIC: Question?           A chat starter: the button you click. Starts at the far left.
#   STARBY: line               What he says.
#                              Several versions? Separate with  |  and he picks one:
#                              STARBY: hi! | hello! | heyyy!
#   FACE: wink                 (optional, on the line under STARBY) the face he makes
#                              while saying it. Faces: wink, glistening (sparkly eyes),
#                              playful (tongue out), grumpy, sad, spittle (spit-laugh),
#                              up, dizzy, mad, yawning
#   > Answer text              A button you can click, answering the STARBY line above it.
#                              At most 5 answers under one STARBY line (Back is added for you).
#   [END]                      After an answer: clicking it closes the chat.
#   [END: line]                Closes the chat, and he says this line as it closes.
#                              (An ending without a line, on "Talk to you later!", gets a
#                              random "byeee!" / "talk soon!" / "see ya! *twinkle*".)
#   [GO TO: name]              After an answer: jump to the STARBY line tagged  #name
#   #name                      At the end of a STARBY line: a tag, so [GO TO: name] can jump here.
#   [NO BACK]                  On a STARBY line: don't add a Back button under it.
#   [DO: something]            After an answer: do something instead of (or after) talking.
#                              Write it in plain words, e.g. [DO: open the shop],
#                              [DO: play tag], [DO: start focus mode], [DO: open settings].
#
# INDENTING (the important part, it's what shows the tree):
#   - Answers go 2 spaces further in than the STARBY line they answer.
#   - Starby's reply to an answer goes 2 spaces further in than that answer.
#   So every step deeper into the conversation moves further right. Use SPACES,
#   not tabs. Blank lines are fine anywhere (use them to keep it readable).
#
#   STARBY: what he says
#     > answer one
#       STARBY: his reply to answer one
#         > deeper answer [END]
#     > answer two [END: okay, bye!]
#
# Every branch has to finish with [END] or [GO TO: ...] somewhere at the bottom.
# (Middle steps get a Back button automatically, which goes up one step.)
#
# HIS VOICE (house rules for anything STARBY says):
#   - all lowercase, no emojis
#   - never mentions "AI", bots, assistants or being a program: he's a star
#   - fun, outgoing, excited, but he's made of starlight and has "seen everything",
#     so questions are a little silly to him
#   - keep a line under ~120 characters so the bubble stays a nice size
# Answers (> lines) can be written normally: they're shown lowercase anyway.
#
# Want something special (only when he's sad, only at night, a game starts...)?
# Just write it as a # note next to it and Claude will wire it up.
